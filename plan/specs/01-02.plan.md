Follow plan/TESTING.md. This design retains the approved Swift/AppKit stack.

## State and invariants

`LimitsStore` remains MainActor isolated. Introduce injected synchronous provider, fallback, usage, VPN and publication operations with production defaults and a test initializer that disables timer/startup; use detached tasks for blocking work. `refresh(force:) async` checks VPN on every timer/wake/manual entry, including while limits are running. A single gate check must be coalesced or fenced so overlapping calls cannot launch duplicate providers or scans. A blocked gate publishes paused from the current snapshot, invalidates a generation, and starts no reads. Completion checks both generation and current VPN policy/state before publication; invalidated work is allowed to finish its synchronous I/O but cannot publish. Keep active flags until physical work finishes so resume cannot duplicate in-flight work; subsequent ticks retry. Resume clears pause only after a successful gate and schedules due limits and usage; startup and resume schedule usage, manual requests schedule it only when due. Track usage separately from `isRefreshing`, with one physical scan at a time. Recheck policy at completion and preserve current snapshot's unrelated fields; never rebuild from pre-await snapshot. Advance `now` on each tick regardless of payload change.

Provider attempts retain existing due/fast intervals, errors, merge and notification behavior. Each due provider runs its CLI, then its fallback only on failure/unavailability (Claude and Codex); Antigravity has none. Do not run fallback for idle providers or successful CLI. One limits batch prevents overlapping launches; publish each result immediately on completion, while retaining a single physical batch guard and isRefreshing until the final provider completes. Each completion merges against current provider state and usage. Persist and reload widgets only for payload changes (providers, pause, usage), retaining generatedAt when payload is unchanged; notifications compare actual current prior state. In-flight work after a VPN change is fenced at completion and the blocked state is published even when no timer has yet detected it.

`AppDelegate.updateIcon()` caches an Equatable rendering key built from paused state, visible provider order, compact, dark appearance, and each visible headline evaluated at `now` (all providers when visible is empty); this covers expiry and shown data. Cache key changes before rendering. No new user-visible strings.
