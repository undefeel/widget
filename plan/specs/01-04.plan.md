# 01-04 implementation plan

Follow plan/TESTING.md. Retain the Shell.run signature and existing string/error contract. Use a single bounded nonblocking poll-driven I/O loop on the calling thread, with Darwin F_SETNOSIGPIPE on the stdin write descriptor; close unused pipe ends after launch and all owned endpoints on every path. Use partial writes and handle EPIPE, EINTR and EAGAIN; never block waiting to write. Drain stdout to EOF on ordinary exit, evaluate stopWhen after reads, and terminate on a matching complete line or timeout. On termination, send TERM then bounded grace and KILL if necessary, and reap the direct child; prevent descendant-held pipes from causing an unbounded wait. Handle launch failure without leaked descriptors. No global signal changes.

Races: child exit versus stdin write (EPIPE), stdout EOF versus process exit, timeout versus read/write readiness, early match versus further output, and TERM versus child exit or ignored TERM. All cleanup paths must close descriptors and reap the process. Preserve stdout accumulated through the matching full line and all output on normal EOF.

CLI.find passes name as zsh positional argument to `command -v "$1"`; keep login lookup and search directories. CodexFetcher uses a shared helper to parse only complete newline-delimited JSON objects, matching top-level numeric ID 1 (excluding boolean), and result/error replies independently of formatting. Ignore malformed, unrelated and trailing partial messages.
