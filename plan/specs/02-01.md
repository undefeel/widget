## Target

Show the remaining CheapVibeCode token balance in the AILimits macOS menu-bar
panel and in the existing "Лимиты AI" widget in all three sizes. The API key is
entered in Settings and stored only in macOS Keychain. The balance refreshes
every five minutes, on launch, on wake, and on manual refresh, independently of
the provider VPN gate. Token balance only: no ruble conversion, percentage, or
limit bar.

## Approved product decisions

- All widget sizes plus the app panel.
- Tokens only, using the existing compact `Fmt.tokens` formatter.
- API key in Settings, stored in macOS Keychain, never in snapshot/defaults/logs.
- Balance requests are independent of the "request limits only with VPN"
  toggle; provider behavior is unchanged.
- The portal dashboard is authenticated HTML behind Cloudflare and is not a
  scraping target. Use `GET https://ru.cheapvibecode.ru/v1/balance` with
  `Authorization: Bearer <key>`, response field `token_balance`.

## Risk list

- Credential disclosure: Keychain only, no key in logs/errors/URLs/snapshot;
  reject redirects so the bearer token cannot leave the API host.
- Concurrency: balance runs before the VPN gate and beside provider/usage work;
  one request per generation, stale completions discarded, current-snapshot
  merge, no blocking of the limits indicator.
- Protocol drift: tolerate extra fields and numeric-string/integral-number
  `token_balance`; reject missing, negative, fractional, or non-numeric values.
- Backward compatibility: old `snapshot.json` without `cheapVibe` must decode;
  widgets render unchanged when no balance exists.
- Keychain after ad-hoc rebuild may prompt again; record it as a manual note.
- Widget space: verify all three sizes after installation.
