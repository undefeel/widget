# 02-01 review addendum — Kimi findings

Status: applied after the final Kimi review of commit `7d8978b`.

The review found no blockers and no majors. Three minor findings were applied
before merge. The parser note about accepting `+5`, `007`, and `1e3` numeric
strings was not changed: those are valid integral numeric representations and
the fail-closed checks still reject garbage, fractional, and negative values.

## F-1 — HTTP error text was frozen in Russian

`BalanceStatus` now carries an optional `errorCode: Int?`. `Store.balanceError`
stores the raw localization key (for example
`"CheapVibeCode вернул ошибку %d"`) plus the HTTP code, and
`BalanceStatus.localizedError` formats it through `LF` at display time.
Popover, Settings, and the widget footer use `localizedError` instead of the raw
key. This keeps HTTP errors localized in both English and Russian.

## F-2 — `.notConfigured` and residual balance

The implemented behavior is intentional: a transient Keychain access failure
must not erase the last successful balance. `notConfigured` leaves the value
untouched; explicit deletion through Settings calls
`balanceCredentialsChanged()`, which clears it, persists the snapshot, and
reloads widgets. The stage plan was reconciled to this behavior.

## F-3 — Missing 403 harness case

`Tests/BalanceHarness.swift` now asserts that HTTP 403 maps to
`.unauthorized`, matching the spec and the Cloudflare-style unauthenticated
response.
