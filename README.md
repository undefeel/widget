# AILimits

Утилита для строки меню macOS и виджет WidgetKit, которые показывают лимиты **Claude**, **Codex** и **Antigravity**.

## Сборка и установка

Xcode не нужен, достаточно Command Line Tools:

```bash
./build.sh           # собрать в build/AILimits.app
./build.sh install   # установить в ~/Applications, зарегистрировать виджет и запустить
./build.sh dmg       # упаковать в build/AILimits-<версия>.dmg
```

Сборка universal (arm64 + x86_64). Подпись ad-hoc, поэтому на другом Mac при первом запуске:
правый клик → «Открыть», или `xattr -dr com.apple.quarantine /Applications/AILimits.app`.

Виджет добавляется через «Редактировать виджеты» на рабочем столе или в Центре уведомлений → **AI Limits**.

## Источники данных

| Сервис | Основной источник | Резервный источник | Как часто |
|---|---|---|---|
| Claude | `claude -p /usage --no-session-persistence` | `claude-statusline.json` (пишет `~/.claude/statusline-command.sh`) | раз в 5 мин |
| Codex | `codex app-server`, метод `account/rateLimits/read` | события `rate_limits` в `~/.codex/sessions/**/*.jsonl` | раз в 2 мин |
| Antigravity | `agy -p /quota` | последние сохранённые значения | раз в 5 мин |

CLI ищутся в `~/.local/bin`, `/opt/homebrew/bin`, `/usr/local/bin` и т. п., а если не найдены там, то через `zsh -lc 'command -v …'`.
Токены приложение не читает: всё делают сами CLI.

### VPN

Перед каждым опросом (раз в 15 с) проверяется VPN: сервис в `scutil --nc list` со статусом `Connected` или маршрут по умолчанию через `utun`/`ipsec`/`ppp`/`wg`.
Если VPN выключен, ни CLI, ни локальные файлы не читаются: остаются последние данные, а в строке меню и виджете появляется значок 🛡⃠.
Когда VPN включится, всё опрашивается сразу. Проверку можно отключить в окне приложения.

Приложение пишет `~/Library/Application Support/AILimits/snapshot.json`, а виджет читает этот файл (у виджета в песочнице есть право только на чтение этого каталога).

## Локализация

Английский и русский (`Resources/{en,ru}.lproj/Localizable.strings`). Ключи — русский текст, `en.lproj` их переводит.
Язык берётся из системы, а для остальных языков используется английский. Отдельно для приложения язык можно выбрать в
«Системные настройки → Основные → Язык и регион → Приложения».

## Иконки

`tools/make_icons.swift` при сборке берёт иконки из установленных `Claude.app`, `ChatGPT.app` (иконка Codex) и `Antigravity.app`.
Цветные иконки используются в окне и виджете, а из них же вырезаются монохромные силуэты для строки меню.
Если приложение не установлено, вместо иконки будет SF Symbol. Файлы иконок в репозиторий не кладутся.

У Antigravity показываются только квоты Gemini: Claude и GPT внутри Antigravity отдельными окнами не выводятся.

В строке меню для каждого сервиса показан самый «узкий» лимит, то есть максимальный процент использования среди его окон.
Пока все лимиты ниже 70%, значок монохромный; с 70% проценты оранжевые, с 90% красные. Есть компактный вид — только значок.

## Панель агентов

Левый клик по значку открывает панель: карточки агентов с лимитами, строка-сводка за неделю и кнопки запуска CLI.
Правый клик — меню: запустить агента, обновить, статистика токенов, настройки. `⌃⌥⌘A` запускает агента по умолчанию
(выбирается в настройках вместе с терминалом: Терминал, iTerm или Ghostty).

### Статистика токенов

Раз в 15 минут приложение читает локальные логи за последние 7 дней: `~/.claude/projects/**/*.jsonl` (Claude Code),
`~/.codex/sessions/**/*.jsonl` (Codex) и SQLite-базы разговоров `~/.gemini/antigravity{-cli,}/conversations/*.db`
(Antigravity, CLI и IDE; открываются только на чтение с `immutable=1`). Считается вход + запись в кэш + выход,
по дням и моделям; чтение из кэша не учитывается.

### Уведомления

Когда окно лимита доходит до порога (по умолчанию 95%), приходит уведомление — один раз за период окна.
Отдельно можно включить уведомление о сбросе лимита. Рядом с порогом (меньше 15 пунктов) лимиты опрашиваются каждые 90 с.

Виджетов два: «Лимиты AI» (маленький, средний, большой) и «Самый узкий лимит» (маленький).
